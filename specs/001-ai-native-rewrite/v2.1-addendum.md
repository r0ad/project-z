# v2.1 增量规格：AI 操作、备份与更新

> 本文件是 `spec.md` / `plan.md` 的增量补充，不改变 v2.0 的核心闭环与本地优先原则。
> 状态：已实现，待真实 WebDAV / GitCode 凭据与 Windows 非沙箱安装验证。

## 1. AI 副驾操作项目

### 用户故事

- 作为用户，我可以在「问问点点」里用自然语言查询项目列表、查看项目详情，不需要自己点进页面。
- 作为用户，我可以说「把 T1 的目标改成完成三端验收」「删除 T1」，点点会先展示确认卡；我点「同意并执行」后才真正修改。
- 作为用户，我可以在确认前点「先不改」，项目数据保持不变。

### 功能需求

1. 工具白名单固定为 `list_projects`、`get_project`、`create_project`、`update_project`、`delete_project`；不得开放任意 SQL 或文件系统工具。
2. 只读工具自动执行，结果回传模型；最多 4 轮，防止工具循环。
3. 写工具必须先写入 `ai_tool_calls`（`pending`），聊天页展示操作摘要与「需确认」标记。
4. 用户确认后逐条执行，写审计 `completed` / `failed`，并把工具结果回传模型生成最终回复；拒绝则写 `rejected`，不修改数据。
5. 确认卡展示期间禁止继续发送新消息。
6. 所有工具调用必须可在 `ai_tool_calls` 中追溯：工具名、参数、结果摘要、耗时、状态。

### 验收

- `flutter test test/data/project_tools_test.dart` 覆盖工具定义、读写标记、CRUD、错误返回。
- Windows 实机对话「Create a project named T1 with goal G1」→ 确认 → 项目存在；「Delete project T1」→ 确认 → 项目不存在。
- 只读 `list_projects` 不再出现在确认卡里。

## 2. 备份与恢复

### 功能需求

1. 本地导出 14 张表为 JSON，格式标识 `diandian-backup`、版本 `1`，包含 `exportedAt` 与应用版本。
2. **不导出 API Key**（Key 在系统安全存储，不在数据库）；WebDAV 密码、GitCode token 同样不导出。
3. 导入前提示会覆盖本地数据；导入在事务内完成，失败回滚并提示格式错误。
4. 导入后刷新首页与列表（`AppEvents.bump()`）。
5. WebDAV：固定文件名 `diandian-backup.json`，Basic Auth；支持配置、测试、上传、下载并恢复。
6. GitCode：OpenAPI v5 contents，支持配置 `owner/repo`、分支、路径、token；先查 sha，再 POST/PUT；支持测试、上传、下载并恢复。
7. 凭据只存系统安全存储；界面只显示是否已配置，不回显密码/token。

### 验收

- `test/data/backup_service_test.dart` 覆盖导出、无 Key、导入恢复、错误格式。
- `test/data/remote_backup_test.dart` 用本地 HTTP 服务覆盖 WebDAV PUT/GET、GitCode 首次 POST、二次带 sha PUT、下载 base64 解码。
- Windows 实机本地导出→导入闭环通过。

## 3. 检查更新

### 功能需求

1. 设置页提供「检查更新」，显示当前版本与检查结果。
2. 默认清单为 GitHub Release latest；兼容旧 `version.json`（对象或数组）。
3. 支持从 `assets` 或 `downloads` 解析 Windows 安装包/便携 zip、Android APK、iOS 页面 URL。
4. 比较版本按点分数字；当前版本不低于最新版本时不提示更新。
5. 下载/打开链接使用系统浏览器或默认程序，不在应用内静默下载安装。

### 验收

- `test/data/update_service_test.dart` 覆盖 GitHub latest、无更新、旧数组格式。
- 发布 v2.1.0 后，旧版本客户端可检测到新版本并打开对应资产。

## 4. Windows 分发

### 功能需求

1. GitHub Release 同时提供 `diandian-windows-setup.exe`（Inno Setup 安装包）与 `diandian-windows-x64.zip`（免安装）。
2. 安装包默认按用户安装（`PrivilegesRequired=lowest`），安装向导允许修改路径，创建开始菜单项与可选桌面快捷方式，提供卸载项。
3. 安装包内包含 VC++ 运行库，缺失时静默安装。
4. Android APK、iOS 未签名 zip 继续由 Release workflow 产出。

### 验收

- 本地 `ISCC.exe /DMyAppVersion=2.1.0 installer/diandian.iss` 编译成功。
- 在非沙箱 Windows 用户态运行安装包，自定义目录安装成功、快捷方式可用、卸载干净。
- tag `v2.1.0` 的 Release 资产包含 setup.exe、便携 zip、APK、iOS zip。

## 5. 非目标

- 不做云同步、多用户、端到端加密备份。
- 不做任意第三方工具/MCP 接入；工具白名单保持最小。
- 不做应用内自动覆盖安装 APK/EXE；只打开下载页或安装包。
