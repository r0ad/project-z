产品闭环

从目标到经验，一条闭环。

不是又一个待办清单。点点围绕真实的项目推进方式设计：每一步都有 AI 参与，但每一步都由你确认。

  1. 01

    目标

    说出想做的事，AI 把它改写成 SMART 目标，再拆成一条条可勾选的里程碑。

  2. 02

    执行

    一条日志记下进展、卡点和下一步；进度由里程碑完成度自动推导。

  3. 03

    分析

    AI 读取项目上下文，指出风险、给出建议、生成周报；不满意就继续追问。

  4. 04

    沉淀

    项目结束，经验进知识库：打标签、关联项目、收藏，下次立项直接复用。

隐私与数据

项目是你的，
数据也是。

点点的默认存储是手机里的 SQLite。没有账号体系，也没有业务后端；备份到哪、AI 用哪家，都由你决定。

  • 本地优先 — 项目、日志、知识默认写入本机数据库，不经过第三方。
  • 备份自主 — 需要灾备时，导出到你自己的 GitCode 仓库，随时可以恢复。
  • AI 直连 — API Key 只存在本机，请求直接发给你选择的模型供应商。

上手

三分钟上手。

第一次打开点点，按这几步走就够了。

第一次打开，先做什么？

点「新建项目」，填项目名称和一句目标描述；也可以直接从内置模板里选一个。AI 会生成 SMART 目标、关键里程碑与计划，确认后即可开始记录。

之后每完成一个里程碑，进度会自动更新，不用手工改百分比。

怎么接上自己的 AI？

进入「我的 → AI 设置」，选择供应商，填入自己的 API Key 与模型，测试连接后启用。Key 只保存在本机数据库。

  • DeepSeek
  • 硅基流动
  • OpenAI
  • Kimi
  • 阿里云通义千问
  • 自定义兼容端点
分享码是什么？

把一份 AI 配置打包成可复制的分享码，别人导入后即可使用同样的模型配置。

它只是本地的对称编码，不带服务端密钥，也不应被当作保密手段——请只分享给自己信任的人。

换手机或重装，数据还在吗？

数据默认只在本机。换设备前先在「我的 → GitCode 备份」把数据库备份到你的仓库，新设备配置同一仓库后从云端恢复即可。

没有备份就换设备，数据不会自动跟着走——这一点和云端笔记 App 不同。

支持哪些平台？

当前提供 Android 安装包。其他平台尚未发布，也没有单独的下载渠道；进展会更新在版本记录里。
