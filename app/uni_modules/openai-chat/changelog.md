# 更新日志

## [1.0.0] - 2024-12-19

### 新增功能
- 🎉 首次发布 OpenAI Chat uni-app 插件
- ✨ 完整的 OpenAI API 工具类，支持多种 API 提供商
- 💬 开箱即用的聊天组件，支持流式和非流式响应
- 📚 智能历史对话管理，自动保存和切换对话
- 🔧 完整的函数调用支持，可注册自定义函数
- 🎨 现代化的聊天界面设计，支持多种消息类型
- ⚙️ 灵活的配置系统，支持运行时配置更新
- 📱 全平台兼容，支持 H5、小程序、App 等

### 核心特性
- **OpenAI API 工具类** (`openai-api.js`)
  - 基础聊天完成（Chat Completion）
  - 流式响应处理（Streaming Response）
  - 历史对话管理（Conversation Management）
  - 函数调用支持（Function Calling）
  - 图像生成（Image Generation）
  - 文本嵌入（Text Embedding）
  - 语音转文字（Speech to Text）
  - 对话导入导出（Import/Export）
  - Token 估算（Token Estimation）

- **聊天组件** (`openai-chat.vue`)
  - 美观的聊天界面
  - 实时流式响应显示
  - 配置面板集成
  - 错误处理和提示
  - 消息历史显示
  - 函数调用可视化
  - 响应式设计

### 技术实现
- 基于 `uni.request` 实现跨平台 HTTP 请求
- 支持流式响应的模拟实现
- 完整的错误处理和重试机制
- 内存中的对话历史管理
- 灵活的函数注册和调用系统
- 响应式的 Vue 组件设计

### 兼容性
- ✅ H5 浏览器
- ✅ 微信小程序
- ✅ 支付宝小程序
- ✅ 百度小程序
- ✅ 字节小程序
- ✅ QQ 小程序
- ✅ 快手小程序
- ✅ 京东小程序
- ✅ App (Android/iOS)

### 默认功能

- 内置数学计算函数

- 智能消息滚动
- 配置持久化
